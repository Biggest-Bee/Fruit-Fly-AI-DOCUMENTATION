# Fruit-Fly-AI-DOCUMENTATION
This is the documentation of the app that I am building.

## Summary of the app: 
This is app is a fruit fly that will help you code. You can train it or use it. The fruit fly cannot see anything outside of the file explorer located in the app. You can talk to the fly(type to the fly) and watch it fly around inside the 3D environment.

## How to start up the app:
This app cannot be used yet since it's still in development. Once it is out of development, you can buy it for $9.99/month or $99.99/year. When you install it, you will have to navigate to the env.example file in the File Explorer(C:\Users\[YOUR_USERNAME]\Downloads\Fruit fly ai\env.example) on your Windows and change it to .env, then, you will insert your Gemini API key and your GitHub Personal Access Token(PAT) in the designated areas. Then double click the Fruit Fly AI.bat file to start the app.
